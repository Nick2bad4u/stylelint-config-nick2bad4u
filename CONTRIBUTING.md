# Contributing

Thanks for helping improve `stylelint-config-nick2bad4u`.

## Development

1. Install dependencies with `npm install`.
2. Make changes to `stylelint.config.mjs`, `index.d.ts`, or docs.
3. Run `npm run verify` before opening a pull request.

## Pull requests

- Keep changes focused.
- Explain why config rules or dependency changes are needed.
- Include compatibility notes when changing Stylelint plugin or preset behavior.
